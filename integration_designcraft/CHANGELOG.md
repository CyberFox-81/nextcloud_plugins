# Changelog

## 0.1.0 – 2026-10-11

First release.

- App ID `integration_designcraft`: "Edit in DesignCraft" in the Files action menu for DesignCraft or IDML files (Nextcloud 33–35)
- Editor page with DesignCraft 0.6.0 (commit 16a7365) in an iframe
- Save writes back over WebDAV with conflict detection; new formats and exports ask for a name and folder
- Read-only files save as a copy
- Optional "open documents in DesignCraft when clicked", per user, with an admin default
