# Changelog

## 0.1.0 – 2026-10-10

First release.

- App ID `integration_effectcraft`: "Edit in EffectCraft" in the Files action menu for video or EffectCraft project files (Nextcloud 33–35)
- Editor page with EffectCraft 0.7.0 (commit 4b58cd2) in an iframe
- Save writes back over WebDAV with conflict detection; new formats and exports ask for a name and folder
- Read-only files save as a copy
- Optional "open EffectCraft projects in EffectCraft when clicked", per user, with an admin default
