# Changelog

## 0.1.0 – 2026-10-10

First release.

- App ID `integration_filmcraft`: "Edit in FilmCraft" in the Files action menu for video or FilmCraft project files (Nextcloud 33–35)
- Editor page with FilmCraft 0.6.0 (commit 2ff3f5e) in an iframe
- Save writes back over WebDAV with conflict detection; new formats and exports ask for a name and folder
- Read-only files save as a copy
- Optional "open videos and projects in FilmCraft when clicked", per user, with an admin default
