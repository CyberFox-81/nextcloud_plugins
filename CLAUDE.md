# nextcloud_plugins — instructions for agents

This repository hands out the latest installable archive of each of the owner's Nextcloud apps until they are in the Nextcloud App Store. The README is the install guide for people running Nextcloud.

- **Whenever one of the owner's Nextcloud apps gets a new version** (today `integration_pdfcraft`, `integration_wordcraft`, `integration_deckcraft`, `integration_cadcraft`, `integration_photocraft`, `integration_vectorcraft`, `integration_filmcraft`, `integration_effectcraft`, `integration_gridcraft`, `integration_soundcraft` and `integration_designcraft`; all but the first two are generated from `template/`, see `template/README.md`), build its archive with `make dist` in the app's repository and publish it here with `scripts/update-plugin.py <archive>`. Commit as `<app_id> <version>` and push. Do this as part of finishing the app update, without being asked again.
- One folder per app id, holding only `<app_id>.tar.gz` (the latest version, stable name so download links don't change) and that app's `CHANGELOG.md`. Don't keep old versions; git history has them.
- `README.md`'s app table (between the `plugins:` markers) and `SHA256SUMS` are generated by the script. Edit the rest of the README by hand.
- A new app: add it with the script, then mention its source repository on the README's "Source code" line and its "Edit in …" entry under "Check it worked".
- Never commit App Store signing keys (`*.key`) or certificates' private parts.
